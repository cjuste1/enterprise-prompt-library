## Purpose
Design a customized AI learning journey for a 
specific business role — with tools, use cases, 
milestones, and assessment checkpoints.
Turns generic AI training into role-relevant, 
immediately applicable learning.

---

## Industries
All industries implementing AI tools

---

## Input Variables
| Variable | Description |
|----------|-------------|
| {{job_role}} | Specific role e.g. HR Manager |
| {{department}} | Department name |
| {{current_ai_comfort}} | none / basic / intermediate |
| {{priority_use_cases}} | Top 3 tasks to automate or improve |
| {{available_tools}} | AI tools approved for this team |
| {{timeline}} | Available learning time e.g. 4 weeks |
